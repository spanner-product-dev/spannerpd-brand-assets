about these samples

All sizes are computed by multiplying the base pixel values from the Spanner visual skill by the scale factor. The type hierarchy and relative proportions remain constant — only the absolute sizes change. Use these pages to evaluate which scale feels right for your output surface (large-format screen, standard web, dense document, etc.) before committing to a size.
