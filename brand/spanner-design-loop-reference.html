spanner‑design‑loop

An internal review loop that runs up to four design iterations before anything reaches the user. No unreviewed drafts. Every visual output passes three expert reviewers — and now includes logo selection and alignment as first-class compliance checks.

what it does

Instead of generating a first draft and handing it over, the design loop produces, critiques, and refines visual output silently — presenting only work that all three reviewers accept.

applies to
Any visual deliverable — HTML, PPTX, DOCX, SVG, infographic, email template
brand references
Loads /spanner-brand-visual-120 (Steps 6, 7, 9 for logo) and /spanner-brand-voice before every build
iteration limit
Maximum four drafts. Unresolved issues at Draft 4 are noted in the design notes handoff.
what the user sees
Final output + a short design notes section covering logo choice, alignment, and brand decisions.

how it works

Six steps run internally before output surfaces. Steps 3–5 repeat until all reviewers pass.

0
load brand references
Reads /spanner-brand-visual-120 in full — with special attention to Step 6 (logo spec), Step 7 (file library and selection logic), and Step 9 (HTML baseline and header alignment). Also reads /spanner-brand-voice. These two skills are the design constitution.
1
understand the brief
Confirms output format, purpose, audience, required content, background mode, every logo placement location, and special constraints. Nothing is built until all are answered.
2
build Draft 1 — select and place the logo
Selects the correct logo file for each placement based on background mode, applies it at the correct size (height:45px for HTML), and applies the baseline alignment spec for any logo appearing in a header row alongside a pipe and label. Full brand spec applied throughout.
silent
3
run the three-reviewer critique
Design Director checks logo file selection, clearspace, and header alignment first — before any other visual criteria. Subject Matter Expert and Project Manager check their domains. Issues are flagged as specific, actionable items.
silent
4
iterate until all three pass
Every flagged issue is fixed and re-reviewed. Runs for up to four drafts. Unresolved issues at Draft 4 are carried into the design notes.
silent · repeats
5
present final output with design notes
The finished file surfaces alongside a design notes section: logo file chosen, alignment approach, other brand decisions, limitations, and any open issues.

The wordmark SVG has descender space at the bottom — visible letter strokes occupy ~22–68% of SVG height. Using align-items:flex-end anchors all three elements at the same bottom edge. The pipe and label then use margin-bottom to lift to the correct optical baseline.

the three reviewers

All three must pass before output is shown. Reviewer A now leads with logo compliance.

Reviewer A
Design Director
Visual craft, brand fidelity, logo compliance
  • Correct logo file for this surface and background
  • Logo from approved folder — not Archive
  • height:45px; no skew, rotation, shadow, or stroke
  • Header: align-items:flex-end; pipe 21px/mb14; label mb11
  • Clearspace respected on all sides
  • Inter — 120% type scale exact
  • Navy text; white/navy backgrounds
  • Azure accents — one method only
  • Lowercase headers; no ALL CAPS
  • Feels like a premium studio made it
Reviewer B
Subject Matter Expert
Content accuracy, completeness, usefulness
  • All required information present
  • Hierarchy matches importance
  • Precise labels — no generic copy
  • Data and facts correct
  • No filler or placeholder text
  • Clear for the target audience
  • Nothing missing; nothing irrelevant
Reviewer C
Project Manager
Usability, clarity, goal achievement
  • Purpose obvious in < 3 seconds
  • Single, specific call to action
  • Structure fits content and format
  • No dead ends
  • Appropriate delivery context
  • No unexplained jargon
  • Achieves stated goal

iteration budget

Maximum four drafts. Intermediate work and critique summaries are never shown.
